# CalyxOS System WebView Installer
Magisk module to install CalyxOS System WebView. (arm64 only)

# Download
- [Latest release](https://github.com/A4Alpha/calyxos-webview-module/releases/download/v1.0.0/calyxos_webview_arm64_110.0.5481.65.zip)

# How to receive updates?
- To receive updates add this repository to your F-Droid app or client: [https://calyxos.gitlab.io/calyx-fdroid-repo/fdroid/repo?fingerprint=C44D58B4547DE5096138CB0B34A1CC99DAB3B4274412ED753FCCBFC11DC1B7B6](https://calyxos.gitlab.io/calyx-fdroid-repo/fdroid/repo?fingerprint=C44D58B4547DE5096138CB0B34A1CC99DAB3B4274412ED753FCCBFC11DC1B7B6)
- Now updates can be installed through F-Droid using this [link](https://f-droid.org/en/packages/com.android.webview) after installing the module.

# Installation
- Make sure you have Magisk installed & simply install the downloaded module using Magisk UI or Fox's Module Manager.
- Upon installation if apps don't work/force close then reinstall Webview app through [apk](https://github.com/A4Alpha/calyxos-webview-module/releases/download/v1.0.0/WebView.apk) or use [F-Droid](https://f-droid.org/en/packages/com.android.webview).

# Troubleshooting
- Check if the right Android System Webview is displayed & selected in Settings>System>Developer Options>WebView implementation.
- You might need to install/update [CalyxOS Trichrome Library](https://f-droid.org/en/packages/org.chromium.trichromelibrary) through F-Droid before using/updating [Webview](https://f-droid.org/en/packages/com.android.webview). (Apps will be visible only after adding the repository)
